OPTION 1: Tree-Level Lock-Free Reads (Best Performance)
--------------------------------------------------------
Instead of locking during selection, use "optimistic reading":
- Read tree structure without locks
- Only lock when MODIFYING tree (expansion, backprop)
- Accept that you might read slightly stale values during selection

This is safe because:
- In Python, reading a reference is atomic
- Stale UCT values don't break correctness, just efficiency
- Expansion and backprop still use locks for correctness

Expected speedup with 4 workers: 3.0-3.5x

Implementation:
```python
def wu_uct_selection(self, node, worker_id):
    current = node
    path = [current]
    task_id = self.get_task_id()
    
    while not current.state.is_terminal():
        # NO LOCK - read tree structure optimistically
        if not current.is_fully_expanded():
            return current, path, task_id
        
        if not current.children:
            break
        
        # NO LOCK - select child using current values
        action_idx = current.select_action_wu_uct(self.exploration_constant)
        if action_idx is None or action_idx >= len(current.children):
            break
        
        current = current.children[action_idx]
        path.append(current)
    
    return current, path, task_id
```

Only lock in safe_expand() and wu_uct_backpropagate().

OPTION 3: Use Root Parallelization Instead (Alternative Approach)
------------------------------------------------------------------
Instead of shared tree with locks, run multiple independent trees:
- Each worker has its own tree
- No locks needed at all!
- Combine results at the end

Implementation:
```python
def run_parallel(self):
    results = []
    
    def worker_loop(worker_id):
        # Each worker gets independent solver
        solver = WUUCTSolver(self.problem, self.iterations // self.num_workers, 1)
        best = solver.run()
        results.append(best)
    
    # Run workers
    threads = [threading.Thread(target=worker_loop, args=(i,)) 
               for i in range(self.num_workers)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    
    # Return best solution across all workers
    return max(results, key=lambda s: s.get_reward())
```

def remove_virtual_loss_and_update(node, reward):
