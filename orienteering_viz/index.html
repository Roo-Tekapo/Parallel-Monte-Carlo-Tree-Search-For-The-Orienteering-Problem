📖 Parallel MCTS for the Orienteering Problem — Guide & Theory

1. The Orienteering Problem (OP)

The Orienteering Problem is an NP-hard combinatorial optimization problem combining aspects of the Knapsack Problem and the Traveling Salesperson Problem (TSP). Given a set of $N$ locations where node $0$ is the Start, node $1$ is the End, and each node has coordinates $(x_i, y_i)$ and score $S_i$, the objective is to find a route from Start to End that maximizes total collected score without exceeding budget $T_{max}$: 

Maximize sum(S_i) subject to Distance(Tour) <= T_max

2. Monte Carlo Tree Search (MCTS) Phases

  • Selection: Traverse tree from root using UCT until reaching a node with unexpanded actions.
  • Expansion: Add a feasible next node to the tree that still reserves budget to return to End.
  • Simulation (Rollout): Complete random or heuristic route to End, collecting total tour score.
  • Backpropagation: Update visit counts $N$ and total reward $Q$ back to root.

3. Parallel Coordination Strategies

Tree-Parallel (Standard UCT)

Workers share a single tree with lock emulation. Best for small numbers of threads before lock contention increases.

Virtual Loss (VL-UCT)

Workers temporarily subtract penalty $L$ from nodes along their path during selection, discouraging other workers from duplicate exploration.

WU-UCT (Weighted Update)

Separates Expansion and Simulation workers via a WorkUnit queue. Incorporates unobserved simulation counts $O$ directly into the exploration term.

Root Parallel

Each worker maintains an independent search tree without lock contention, aggregating statistics at the root for decision making.
